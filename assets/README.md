# Image provenance

`signal-trace-banner.jpg` is derived from **“1996—Original photo of
oscilloscope trace”** by Benz / National Institute of Standards and Technology.

- Source: <https://commons.wikimedia.org/wiki/File:1996--Original_photo_of_oscilloscope_trace_(5940300289).jpg>
- Copyright: public domain in the United States as a work of the U.S. federal
  government
- Changes: cropped to the oscilloscope display, converted to a black/red
  duotone, resized to 1800 × 600, and stripped of metadata
- Generative AI: none

The Wikimedia Commons file page requests the byline “Benz/NIST” when the image
is reused. The profile README includes that credit.
